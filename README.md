# ГитарПрактика — Android-приложение для занятий на гитаре (личное использование)

Нативное приложение на Kotlin + Jetpack Compose. Работает офлайн. Интернет нужен только для просмотра табов.

## Что умеет

| Раздел | Возможности |
|---|---|
| **Уроки** | 24 урока на 3 уровня. В каждом уроке: разминка → базовое упражнение (со ссылкой на методику: Justin Guitar, Berklee/Leavitt, Carcassi, Giuliani, Petrucci, Troy Grady и др.) → разбор песни (аккорды, ритм, таб). Таймер по блокам, метроном с разгоном прямо в упражнении |
| **Режим обучения** | Уровень, минут в день (10–90), дней в неделю, фокус (баланс / техника / песни). Длительность блоков урока пересчитывается автоматически |
| **Тюнер** | Алгоритм YIN, 11 строев: стандартный, пониженные (Eb, D, Drop D, Drop C, C), повышенные (F, F#), открытые (Open G, Open D, DADGAD). Автоопределение струны, эталонный звук, калибровка A4 |
| **Практика** | Метроном (точный до сэмпла, tap tempo, тренажёр скорости); **ритм-тест** по микрофону с калибровкой задержки; **смены аккордов** с автоподсчётом по микрофону; **слух** — мажор/минор, открытые и септаккорды |
| **Прогресс** | Минуты по дням, серия, недельная цель, пройденные уроки, рекорды темпа, смен аккордов и ритма |
| **Табы** | Офлайн-просмотр **Guitar Pro (gp3–gp7, gpx), MusicXML** с нотами, табом и воспроизведением (alphaTab), PDF и текстовых табов. Сохранение с guitarmaestro.ru в один тап (файлы скачиваются, текст копируется), импорт файлов, привязка к уроку. Встроенный песенник общедоступных пьес |
| **Напоминания** | В выбранные дни и время, только если дневная цель ещё не выполнена |

## Как получить APK

1. Каждый push собирает APK в GitHub Actions (workflow **Build APK**).
2. Откройте вкладку **Actions** → последний успешный запуск → артефакт **GuitarPractice-apk** (zip с `app-debug.apk`).
3. Перекиньте APK на телефон, разрешите «Установку из неизвестных источников», установите.

Локальная сборка (нужен Android SDK): `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`.

## Ограничения (осознанные)

- **Табы популярных песен не вшиты в APK.** Это чужие произведения: их распространение в составе приложения — нарушение авторских прав, а транскрипции «по памяти» были бы неточными. Вместо этого вы сами сохраняете табы с сайта в приложение (кнопка ⬇ во встроенном браузере) — дальше они живут офлайн и привязаны к урокам. Вшиты только упражнения и пьесы в общественном достоянии.
- Распознавание аккордов и ритм-тест работают по микрофону телефона и дают приблизительный результат: лучше всего в тишине, без Bluetooth-наушников, после калибровки.
