# ГитарПрактика — Android-приложение для занятий на гитаре (личное использование)

Нативное приложение на Kotlin + Jetpack Compose. Работает офлайн. Интернет нужен только для просмотра табов.

## Что умеет

| Раздел | Возможности |
|---|---|
| **Уроки** | 24 урока на 3 уровня. В каждом уроке: разминка → базовое упражнение (со ссылкой на методику: Justin Guitar, Berklee/Leavitt, Carcassi, Giuliani, Petrucci, Troy Grady и др.) → разбор песни (аккорды, ритм, таб). Таймер по блокам, метроном с разгоном прямо в упражнении |
| **Режим обучения** | Уровень, минут в день (10–90), дней в неделю, фокус (баланс / техника / песни). Длительность блоков урока пересчитывается автоматически |
| **Тюнер** | Алгоритм YIN, 11 строев: стандартный, пониженные (Eb, D, Drop D, Drop C, C), повышенные (F, F#), открытые (Open G, Open D, DADGAD). Автоопределение струны, эталонный звук, калибровка A4 |
| **Играть с проверкой** | В духе Yousician: ноты таба едут по ленте к линии, приложение слушает гитару и засчитывает каждую ноту. Режимы «В темпе» (под метроном) и «Ждать меня» (лента ждёт правильную ноту), скорость 40–100%, повтор фрагмента, звёзды, опыт и уровни. Работает со встроенными пьесами, упражнениями и вашими Guitar Pro табами |
| **Практика** | Метроном (точный до сэмпла, tap tempo, тренажёр скорости); **ритм-тест** по микрофону с калибровкой задержки; **смены аккордов** с автоподсчётом по микрофону; **слух** — мажор/минор, открытые и септаккорды |
| **Прогресс** | Минуты по дням, серия, недельная цель, пройденные уроки, рекорды темпа, смен аккордов и ритма |
| **Табы** | Офлайн-просмотр **Guitar Pro (gp3–gp7, gpx), MusicXML** с нотами, табом и воспроизведением (alphaTab), PDF и текстовых табов. Сохранение с guitarmaestro.ru в один тап (файлы скачиваются, текст копируется), импорт файлов, привязка к уроку. Встроенный песенник общедоступных пьес |
| **Редактор табов** | Свой таб: лады, длительности, приёмы; звук и игра с проверкой; экспорт в Guitar Pro (.gp) |
| **Минусовки** | MP3, M4A/AAC, OGG, Opus, FLAC, WAV: скорость без изменения тона, транспонирование, повтор A–B, привязка к уроку |
| **Напоминания** | В выбранные дни и время, только если дневная цель ещё не выполнена |

## Как получить APK

1. Каждый push собирает APK в GitHub Actions (workflow **Build APK**).
2. Откройте вкладку **Actions** → последний успешный запуск → артефакт **GuitarPractice-apk** (zip с `app-debug.apk`).
3. Перекиньте APK на телефон, разрешите «Установку из неизвестных источников», установите.

Локальная сборка (нужен Android SDK): `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`.

## Ограничения (осознанные)

- **Табы популярных песен не вшиты в APK.** Это чужие произведения: их распространение в составе приложения — нарушение авторских прав, а транскрипции «по памяти» были бы неточными. Вместо этого вы сами сохраняете табы с сайта в приложение (кнопка ⬇ во встроенном браузере) — дальше они живут офлайн и привязаны к урокам. Вшиты только упражнения и пьесы в общественном достоянии.
- Распознавание аккордов и ритм-тест работают по микрофону телефона и дают приблизительный результат: лучше всего в тишине, без Bluetooth-наушников, после калибровки.

## Сторонние компоненты

- [alphaTab](https://alphatab.net) 1.8 — MPL-2.0 (`app/src/main/assets/alphatab/LICENSE`)
- Шрифт Bravura — SIL OFL 1.1; саундфонт Sonivox — Apache 2.0 (Android Open Source Project)
- Сборка debug-подписью: для личной установки этого достаточно.

# Совёнок Уху — развивающая игра для ребёнка 6 лет (модуль `kidsgame`)

Отдельное Android-приложение в этом же репозитории (только горизонтальный экран): неоновый раннер в духе Geometry Dash (своя графика, свои уровни и музыка), работает **полностью офлайн**, без рекламы и голоса.

**Как играть.** Совёнок-кубик Уху бежит по трассе, тап — прыжок. Перед развилкой он останавливается, и появляется задание; ответы — это порталы, ребёнок нажимает на нужный, и Уху прыгает в него. Время на ответ не ограничено. На задание две попытки: с первой — 1 очко, со второй — ½, после второй ошибки правильный портал подсвечивается (без очка). После ошибки порталы блокируются на 1,5 с — перебором не пройти. Звезда за раунд — от 4 очков из 5.

| Раздел | Уровни 1 → 5 |
|---|---|
| **Лес букв** (чтение) | первая буква слова → короткие слова → слово к картинке → слово из слогов → загадки |
| **Река чисел** (счёт) | счёт до 10 → сложение с картинками → вычитание с картинками → примеры до 10 → до 20 и «какое число спряталось» |
| **Пещера загадок** (логика) | узоры и тени → что лишнее → узоры посложнее и память → числовые ряды → сложные ряды |
| **Испытание** | 5 режимов: Кубик (3 уровня), Ракета, Шарик, НЛО, Волна (по 2 уровня) и «Всё вместе» с воротами смены режима; «Тренировка» с точками сохранения; уровни открываются за звёзды. Все уровни проверены автоматическим решателем на проходимость |
| **Строитель** | свои уровни на сетке: блоки, шипы, кольца, батуты, ворота режимов; сохранить можно только после того, как сам прошёл уровень (до 8 уровней) |
| **Мастерская** | рисунок на тему с наклейками и галереей |
| **Гардероб** | 8 друзей-персонажей (Уху, Лисёнок, Зайка, Ёжик, Лягушонок, Пингвинёнок, Котёнок, Ветерок); у каждого свой выбор из 13 цветов и 5 аксессуаров (кепка, очки, бантик, шарф, корона) — за звёзды и пройденные уровни Испытания |
| **Эмоции** | у Уху и всех друзей живые лица: моргают, оглядываются, радуются правильному ответу, грустят при ошибке. На стартовом экране и на карте совёнка можно тапать: голова — разные реакции, животик — щекотка, много тапов подряд — голова кружится, если долго не трогать — засыпает |
| **Ключи Испытания** | Испытание (и строитель) открывается тремя ключами: звезда в Лесу букв, на Реке чисел и в Пещере загадок; за комплект — 3/5/10/15 минут (настраивается, можно выключить) |

**Для взрослых** (шестерёнка на карте; без кода — долгое нажатие):
- **Время игры**: без ограничений / 15 / 20 / 25 / 30 мин. Считается только время, когда игра на экране. За 2 минуты — предупреждение; начатый забег можно доиграть (до 3 минут сверху). Потом игра «засыпает» на 3 часа. Пауза считается по монотонным часам Android, перевод часов на телефоне её не сокращает.
- **Код из 4 цифр** обязателен для ограничения времени; им же можно разбудить игру раньше.
- Уровни сложности вручную, музыка, звуки, сброс прогресса.

**Лицензии.** Музыка синтезируется кодом, записи не используются: мелодии в общественном достоянии в собственной аранжировке — «Ah vous dirai-je, Maman» (1761), Бетховен «Ода к радости» (1824) и «К Элизе» (изд. 1867), Григ «В пещере горного короля» (1876), Джоплин «The Entertainer» (1902) — и собственная мелодия Испытания. Шрифты Comfortaa и Nunito — SIL OFL 1.1 (`kidsgame/src/main/assets/fonts/`). Картинки — системные эмодзи. Название, графика и уровни Geometry Dash не используются.

**Версии.** `versionName` — то, что видно пользователю (раздел «Для взрослых»): крупные новые функции — следующая целая версия (6.0), небольшие изменения — дробная (5.1, 5.2). `versionCode` — внутренний счётчик, он увеличивается на 1 при каждой сборке, которую ставят на телефон, независимо от `versionName`.

**Обновление** ставится поверх старой версии: тот же пакет `ru.staschig.zvezdy` и тот же ключ подписи (`keystore/debug.keystore` — не менять, иначе Android откажется обновлять), прогресс хранится под прежними ключами.

**APK**: релиз `kids-apk-latest` → `SovenokUhu.apk` (https://github.com/staschig-dotcom/staschig/releases/download/kids-apk-latest/SovenokUhu.apk).
