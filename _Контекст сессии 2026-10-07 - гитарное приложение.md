# Контекст сессии 2026-10-07 — гитарное приложение «ГитарПрактика»

## Что это
Android-приложение (Kotlin + Jetpack Compose) для личного обучения игре на гитаре.
Репозиторий: staschig-dotcom/staschig, ветка `claude/guitar-learning-app-wyjqhf`.
APK (постоянная ссылка, обновляется при каждой сборке):
https://github.com/staschig-dotcom/staschig/releases/latest/download/GuitarPractice.apk
Ставится поверх старой версии (подпись постоянная, `keystore/debug.keystore`).

## Что реализовано
- **Знакомство** при первом запуске: уровень, минут в день, микрофон.
- **«Сегодня»**: план занятия + одна кнопка «Начать занятие». Вкладки: Сегодня / Курс / Инструменты / Прогресс.
- **Занятие-мастер**: «Шаг N из M», нумерованные указания, «🔊 Послушать пример», инструмент шага
  (метроном с разгоном / тренажёр смен аккордов / тюнер / табы песни), одна кнопка внизу; настройка гитары раз в день.
- **Курс**: 24 урока, 3 уровня (разминка → упражнение по методике → песня).
- **Табы**: офлайн Guitar Pro / MusicXML (alphaTab в assets), PDF, текст; сохранение с guitarmaestro.ru кнопкой ⬇;
  18 встроенных интерактивных табов (упражнения + пьесы в общественном достоянии).
- **Микшер в стиле Songsterr**: выбор своей дорожки, mute/solo/громкость, «Сопровождение без меня».
- **Играть с проверкой** (как Yousician): лента нот, распознавание по микрофону, режимы «Послушать / Разучить (лента ждёт) / В темпе»,
  скорость 40–100%, фрагмент и повтор, звёзды, XP, уровни.
- Тюнер (11 строев), метроном, ритм-тест с калибровкой, смены аккордов с автоподсчётом, слух, напоминания.
- Горизонтальная ориентация по умолчанию (настраивается), двухколоночные раскладки.

## Принятые решения и почему
- Табы популярных песен **не вшиты** в APK (авторское право + неточность транскрипций «по памяти»);
  пользователь сам сохраняет их с сайта — дальше они офлайн и привязаны к урокам.
- Сборка APK — в GitHub Actions (в среде разработки нет Android SDK). Скриншоты экранов снимает Paparazzi в CI
  (служебный пререлиз `ui-screenshots`).

## Не проверено на реальном устройстве
- Распознавание нот/аккордов с настоящей гитарой (проверено только на синтезе), звук примеров, микшер, WebView-экраны.

## Важно про наушники
- Пользователь играет в наушниках. Калибровка ритм-теста работает только через динамик (микрофон должен слышать щелчки),
  в наушниках она не пройдёт. Bluetooth-наушники добавляют ~150–250 мс задержки — оценка попадания в такт будет «поздно».
  Режим «Разучить (лента ждёт)» от задержки не зависит.
