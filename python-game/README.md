# Кодонавт

Игра-головоломка про программирование на настоящем Python. Сюжет: ты просыпаешься на звездолёте «Нуль»,
ИИ корабля сломан, и ты чинишь корабль, программируя дронов. 3D (three.js), работает в браузере телефона,
ставится на экран «домой» как приложение и после первого запуска не требует интернета.

9 уровней: последовательность → повороты → `for` → сбор кристаллов → `while` и датчики → `if/else` →
лазеры и `jump()` → функции `def`. Звёзды дают за короткий код (как в спортивном программировании:
не просто решить, а решить красиво).

## Как поиграть

Нужен любой статический веб-сервер. С компьютера:

    cd python-game
    python3 -m http.server 8000

и открыть на телефоне (одна Wi-Fi сеть) `http://<IP-компьютера>:8000`. Так игра работает, но
установка как приложение и офлайн-режим требуют **https** — для этого выложи папку на любой статический
хостинг (GitHub Pages, Netlify, Cloudflare Pages). На Android в Chrome: меню → «Установить приложение».

`?all=1` в адресе открывает все уровни сразу (для родителя).

## Как устроено

| Файл | Что делает |
|---|---|
| `js/levels.js` | Уровни: карта символами, текст, подсказки. Новый уровень = новый элемент массива. |
| `js/sim.js` | Мир без графики: сетка, дрон, датчики, журнал действий. |
| `js/runner.js` | Запускает код ребёнка в Pyodide (настоящий Python), считает шаги, переводит ошибки на русский. |
| `js/scene.js` | 3D-сцена и анимации. |
| `js/game.js` | Интерфейс, редактор с кнопками для телефона, звёзды, сохранения. |
| `vendor/` | three.js и Pyodide (скопированы, чтобы всё работало офлайн). |

Код ребёнка исполняется как обычный Python, но команды дрона пишут действия в журнал, а 3D-сцена
потом проигрывает его. Поэтому можно писать что угодно: переменные, функции, `print()`.

## Проверка

    node python-game/test/solve.mjs

Прогоняет эталонные решения всех уровней через настоящий Python и проверяет сообщения об ошибках.
Если добавляешь уровень — добавь решение в `test/solve.mjs`.

## Идеи на следующий вечер

- Уровни с переменными и списками (датчик возвращает число, его надо сохранить).
- Задачи формата «вход → выход» с автопроверкой — мостик к настоящим олимпиадам.
- Режим «найди баг»: дан сломанный код.
- Больше миров и сюжета (сейчас 9 уровней = один отсек корабля).

## Android-приложение (APK)

Модуль `kodonavt/` оборачивает эту папку в WebView: файлы игры подключаются как assets прямо из
`python-game/`, копий нет. Сборка идёт в GitHub Actions (workflow **Build Kodonavt APK**), APK по постоянной ссылке:

    https://github.com/staschig-dotcom/staschig/releases/download/kodonavt-apk-latest/Kodonavt.apk

Пакет `ru.staschig.kodonavt`, подпись общая с остальными приложениями (`keystore/debug.keystore`, не менять).
Если игра в приложении не стартует, подключи телефон по USB, открой на компьютере `chrome://inspect` и посмотри консоль:
отладка WebView включена в debug-сборке.
