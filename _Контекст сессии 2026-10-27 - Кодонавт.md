# Контекст сессии 2026-10-27 — «Кодонавт», обучающая 3D-игра по Python для сына (10 лет)

## Что это
Игра-головоломка про настоящий Python. Сюжет: юный инженер просыпается на звездолёте «Нуль», ИИ корабля (ИСКРА)
сломан, он чинит корабль, программируя дронов. 9 уровней: move → повороты → for → кристаллы (take) →
while и датчики → if/else → лазеры и jump → функции def. Звёзды за короткий код (par у каждого уровня).
Цель пользователя: обучение Python и спортивному программированию, сын уже знает основы (первый курс).

## Где лежит (ветка `ccr-bb49e084-vcjpgo`, репозиторий staschig-dotcom/staschig)
- `python-game/` — сама игра (HTML + three.js + Pyodide), работает в браузере и офлайн как PWA.
  - `js/levels.js` уровни (карта символами), `js/sim.js` мир, `js/runner.js` мост к Python и русские сообщения об ошибках,
    `js/scene.js` 3D, `js/game.js` интерфейс и редактор с кнопками для телефона.
  - `vendor/` — three.js и Pyodide скопированы (офлайн). `test/solve.mjs` — эталонные решения всех уровней через настоящий Python.
- `kodonavt/` — Android-модуль (WebView), assets берутся из `python-game/` без копий. Пакет `ru.staschig.kodonavt`,
  ключ общий `keystore/debug.keystore` (не менять). Сейчас версия 0.2 (versionCode 2).
- `.github/workflows/build-kodonavt-apk.yml` — тесты уровней + сборка + публикация APK.
  Гитарный `build-apk.yml` ограничен модулем `:app` и своими путями.
- APK: https://github.com/staschig-dotcom/staschig/releases/download/kodonavt-apk-latest/Kodonavt.apk

## Ключевые решения и почему
- Не Godot/Unity, а веб + WebView: пользователь не разработчик, сборка APK уже есть в CI (как у «Совёнка Уху»),
  Pyodide даёт настоящий Python без своего интерпретатора. Свой интерпретатор не нужен.
- Ввод кода на телефоне: кнопки над редактором (move(), for…, else:, цифры, ↵ ⇥ ⇤), отступы ставятся сами.
  Команды вставляются новой строкой после текущей (баг «вставка внутрь скобок» исправлен).
- Python исполняется настоящий; команды дрона пишут журнал действий, 3D проигрывает его. Лимит шагов защищает от
  бесконечных циклов (sys.settrace). Ошибки Python переводятся на русский.
- Оболочку сделали отдельным модулем в этой же ветке, а не в ветке Уху (`wizardly-lamport`), чтобы не трогать игру,
  которую уже ставят ребёнку.

## Что было сломано и починено
- v0.1 падала на старте на Poco 7: пересборка `WebResourceResponse` конструктором со `statusCode`
  бросала IllegalArgumentException (загрузчик assets отдаёт ответ без кода статуса). В v0.2 трёхаргументный
  конструктор и try/catch. Заодно добавлено красное окно фатальных ошибок на экране (`#fatal`).
- Опечатка в карте уровня 6 (лишний пробел) — нашёл тест эталонных решений.

## Проверено / не проверено
- Проверено: тесты всех 9 уровней через Pyodide в Node; браузерный e2e (Chromium, мобильный режим, 3D, ввод кнопками);
  сборка APK в CI; на реальном Poco 7: приложение запускается, меню уровней, первый уровень решается.
- Не проверено на телефоне: клавиатура и вёрстка при вводе, плавность 3D на уровнях 6 и 9, кнопка «Назад»,
  повороты экрана, уровни 2–9, а главное — интересно ли сыну. Сейчас сын тестирует.

## Заметки
- Уровень 9 не заставляет писать функцию: решение циклом короче. Если нужно принудить к `def`, усложнить карту.
- Pyodide в APK добавляет ~15 МБ (APK ~16,8 МБ).
- `?all=1` в адресе открывает все уровни (в APK адреса нет — для проверки уровней использовать веб-версию).
