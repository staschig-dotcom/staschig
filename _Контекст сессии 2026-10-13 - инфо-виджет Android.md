# Контекст сессии 2026-10-13 — инфо-виджет для Android (Xiaomi Mi 10T)

## Что это
Отдельное Android-приложение «Инфо-виджет» (модуль `widget/`, applicationId `ru.staschig.widget`)
в репозитории staschig-dotcom/staschig, ветка `claude/loving-galileo-06lzk4`. С гитарным приложением не связано.
APK (постоянная ссылка, обновляется при каждой сборке этой ветки):
https://github.com/staschig-dotcom/staschig/releases/download/widget-latest/InfoWidget.apk
Подпись постоянная (`keystore/debug.keystore`) — новые версии ставятся поверх.

## Что реализовано
- Виджет на весь главный экран MIUI (сетка 4×6, Mi 10T ≈ 393×873 dp), растягивается.
- Сверху вниз: **часы + дата** (TextClock, нажатие → будильники) и **погода** справа;
  **сообщения** — последние 15 уведомлений (NotificationListenerService, иконка приложения, нажатие открывает
  то же, что уведомление); **календарь внизу** — до 5 событий на сегодня–завтра.
- **Погода**: Open-Meteo (без ключа), при недоступности — запасной wttr.in. Город по-русски или латиницей.
  Обновление раз в 30 минут (WorkManager). Ошибка сети показывает тип исключения (UnknownHost / SSL / Timeout).
- **Календарь**: системный CalendarContract (Google-календарь через синхронизацию аккаунта, без OAuth),
  обновление сразу при изменении календаря (воркер с content-URI-триггером), нажатие открывает событие.
- **Прозрачность фона**: ползунок в настройках (0–100 %), у текста тень для читаемости на светлых обоях.
- Экран настроек: город, доступ к уведомлениям, доступ к календарю, прозрачность, «Добавить на рабочий стол»,
  кнопки MIUI «Автозапуск» и «Батарея: без ограничений».

## Принятые решения и почему
- **Почта отдельно не подключена**: письма приходят уведомлениями и уже попадают в блок сообщений;
  Gmail API = restricted scope, в тестовом режиме OAuth-токен живёт 7 дней.
- **Календарь не через Google API**, а через CalendarContract — тот же результат без проекта в Google Cloud и OAuth.
- **GPS не используется**: для фонового обновления нужен доступ к геопозиции «всегда» — лишнее разрешение.
- Сборка только в GitHub Actions (в среде нет Android SDK). Найден и исправлен тестом баг: дата события выводилась «10.15» вместо «15.10».

## Инструкции для пользователя (Mi 10T, Android 13 / MIUI 14)
- Доступ к уведомлениям: кнопка в приложении → включить «Инфо-виджет». Если «Ограниченная настройка» —
  Настройки → Приложения → Инфо-виджет → ⋮ → «Разрешить ограниченные настройки».
- MIUI обязательно: Автозапуск = вкл., Контроль активности = «Нет ограничений», иначе сервис уведомлений выгружается.
- Ставить на пустой экран; док внизу виджет перекрыть не может.

## Открытые вопросы / не проверено
- На реальном телефоне не проверялось: размер виджета в лаунчере MIUI, вёрстка часов (72sp), тень текста.
- Ошибка «Нет связи с сервером погоды» у пользователя: причина не установлена (VPN / ограничение трафика MIUI /
  блокировка Open-Meteo). Добавлен запасной источник — ждём результат после обновления.
- Telegram: при код-пароле Telegram сам скрывает текст уведомления; при «Защите приложений» MIUI текст,
  вероятно, будет виден в виджете. Предложено (не сделано): скрывать текст для выбранных приложений / белый список приложений.
